# 손으로 잇다

부스용 수어 학습 및 게임 리더보드 정적 웹사이트입니다. 빌드나 서버 설치 없이 GitHub Pages로 배포할 수 있습니다.

- `index.html`: 모음집이 기본 영상인 학습 화면, 개별 수어 5개, 시청 완료 표시
- `leaderboard.html`: 별도 창에서 여는 순위 화면, 동점 공동 순위, 전체 화면
- `admin.html`: 닉네임/점수 수기 입력, 개별 삭제, JSON 백업 및 복원

## 부스 운영

같은 기기, 같은 브라우저에서 점수 입력과 리더보드 창을 열어 주세요. 점수를 등록하면 리더보드에 자동 반영됩니다. 같은 닉네임도 별도 참가 기록으로 저장됩니다. 점수가 같으면 공동 순위이며 다음 순위는 건너뜁니다(1, 1, 3).

점수와 학습 기록은 브라우저의 localStorage에 저장합니다. 기기나 브라우저가 다르면 자동 공유되지 않습니다. 다른 기기로 옮길 때는 운영자 화면의 기록 내보내기/불러오기를 사용하세요. 기존 기록에 합쳐지며 같은 ID는 중복 추가하지 않습니다. 브라우저 데이터 삭제에 대비해 주기적으로 백업하세요.

운영자 화면은 로그인이나 서버 인증을 제공하지 않습니다. 방문자가 입력해도 해당 방문자의 브라우저 기록만 바뀝니다.

## GitHub Pages

저장소 Settings → Pages → Build and deployment에서 `Deploy from a branch`, `main` / `(root)`를 선택합니다. 하위 경로에서도 동작하도록 모든 자산은 상대 경로로 연결했습니다.

로컬 확인: 이 폴더에서 `python3 -m http.server 8080` 후 `http://localhost:8080`에 접속합니다.

원본 영상 6개를 H.264/AAC MP4로 변환해 웹 호환성을 높였습니다. `assets/all.mp4`가 모음집입니다. 원본 파일은 수정하지 않았습니다.
